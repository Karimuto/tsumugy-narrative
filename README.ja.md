> テキストを高品質の物語にするシンプルなスキルです。物語と短い説明、出典を作ります。

私は医学生で、どうにか難しい概念を短時間で理解する方法はないかと悩んでいました。そこで、絵を書いて覚えるという方法に出会いました。私はAIに絵をかいてもらおうとしました。しかし残念なことにAIは正確な絵を書くことはできませんでした。そこで、絵ではなく絵のような情景を物語にすることを考えつきました。これはとても効果的で、難しい概念の理解にとても役立ちました。友達にシェアしたら、公衆衛生学の統計などがとても簡単に理解できたと、評判が良かったです。単に言葉で物語にするように指示するのでは毎回出力が変わってしまい、「もっと面白い話にして」「どういう比喩なのかわからないから説明して」などとなってしまいます。このスキルでは自己検証スクリプトを同封することで、毎回高品質の物語を作れます。

## 物語

### 鼻の奥の小さな花火大会

うららかな春の昼下がり、空の白い光の下で『春の花粉雪』🌸(花粉)が音もなく鼻の奥にひらひらと舞い込んできた。

鼻の奥で『鼻の花火』🎆(くしゃみ)がぱっと開いてはじけ、乾いた音が痛む頭蓋に高く響き渡った。

『蛇口の鼻』🚰(鼻汁分泌)からは涙のように水がぽたぽたと滴り落ち、冷たい感触が乾いた唇に触れた。

見えない糸を引く『興奮の糸電話』📞(副交感神経)が、甘い花の匂いの奥でちりちりと鳴り続けていた。

やがて『渋滞の煉瓦』🧱(ロイコトリエン)が鼻の通りにうず高く積まれ、『詰まった提灯』🏮(鼻詰まり)が真っ赤に灯った。

鼻🏮を責めるな、騒ぐ裏方を知る者だけが長く不安な春をやっと生き延びる。

## 解説

くしゃみと鼻水と鼻詰まり、花粉症の仕組みを描いた切ない寓話で、花火はくしゃみ、蛇口は鼻水、煉瓦はロイコトリエンを指す。

> 出典：薬理講義 30:12

voice: AK (短編綺譚風)

### 油まみれの旧街道と新幹線

薬の立ち並ぶ市場に『油まみれの旧街道』🛢️(第一世代抗ヒスタミン薬)が脂の匂いを放って長く延びていた。

旧い街道は『脳の関所』🚧(血液脳関門)をやすやすと抜け、昼の白い光までを濁らせていった。

旅人は『眠りの座布団』🛋️(眠気)にどさりと腰を下ろし、冷たい風の音を遠くに聞きながら深く落ちていった。

口には『からからの水筒』🥤(口渇)だけが残り、苦い味が舌に触れて深い不安がじわりと広がっていった。

『固い蛇口』🔩(排尿困難)は錆びてびくとも回らず、新しい旅支度を責める声が通りいっぱいに満ちた。

## Quick start（1分）

2つの道があります。どちらも約1分です。

### Claude アプリ（ターミナル不要）

1. 配布物をダウンロード: [narrative-formatter.skill](dist/narrative-formatter.skill)。
2. Claude アプリを開きます。ハンバーガーメニューからカスタマイズを開き、追加を押します。
3. ファイルをドラッグ＆ドロップします。コード実行を有効にします。
4. チャットで材料とモードを渡します。

https://github.com/user-attachments/assets/e70f9b9c-9f10-4012-85fe-a42d782cffb6

リポジトリ内の同ファイル: [install-claude.mp4](docs/assets/install-claude.mp4)

アップロードに失敗したら配布物を上げ直します。Skills の項目が見えなければコード実行を有効にします。

### Coding agent（ターミナル）

全 Coding agent の第一選択は Npx です。Npx は Node.js に付いてきます。先に入れます: https://nodejs.org/

```bash
npx skills add Karimuto/tsumugy-narrative
npx skills list
```

## 使い方

物語を作るのはスキルの呼び出し一発です。Claude アプリでも ClaudeCode、Codex、Pi、OpenCode のような Coding agent でも打ちます:

```
/narrative-formatter <入力ファイル>。モード: <モード (省略可)>。
```

たとえば、入力と同じ場所に出力する場合:

```
/narrative-formatter "pharmacology2Lect3.pdf"（ファイルのドラッグ＆ドロップも可）。モード: serial。
```

モードは3つです（既定は `fable`）:

- **episodic**: テキストに忠実に、一章ごとに一話完結の物語にする。
- **serial**: 同じ主人公・同じ世界で続ける連作にする。記憶は ledger に引き継ぐ。
- **fable**（既定）: 印象優先で、多少の不正確さは許して心に残す。

## 仕組み

6ステップです。どれもシンプルで、高校生でも追えます。

1. 難しい文章を読み、要点とつながりを見つけます。
2. 人物が動いて感じる小さな場面を作ります。
3. 難しい言葉を比喩で包み、括弧で印を付けます。
4. 登場人物と物に絵文字を1つずつ付けます。同じものには毎回同じ絵文字を使います。
5. 物語の下書きを作ります: 題、物語本文、短い説明、出典マーカー。
6. 自己検証スクリプトを実行します。結果は PASS、CONDITIONAL PASS、FAIL のいずれかです。指摘された所を直します。PASS か CONDITIONAL PASS のものだけ届けます。

連作 (serial) の Thread は Ledger を持ちます。Ledger は世界と人物の状態をためます。新しい話はまず Ledger を読みます。
